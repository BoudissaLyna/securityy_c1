DNS Tunnel Detection

A live pipeline that captures DNS traffic, extracts flow-level features, and sends them to an ML backend for tunnel detection.

tshark Python 3 httpx UDP/TCP port 53 Shannon Entropy
01

How It Works

The pipeline is a producer → transformer → consumer chain. tshark captures every DNS packet live and writes CSV rows to stdout. extractor.py reads those rows, groups them into per-flow records, computes features, then POSTs the JSON to a backend ML server.

tshark
Capture raw DNS packets
→
extractor.py
Aggregate flows + build features
→
POST /analyze
ML backend inference
02

The tshark Capture Command

Run this single command to start the full pipeline. You need sudo because capturing on a network interface requires root privileges.

bash 
sudo tshark -i eth0 \
  -f "udp port 53 or tcp port 53" \
  -T fields \
  -e frame.time   -e ip.src      -e ip.dst \
  -e dns.qry.name -e dns.qry.type \
  -e dns.resp.type -e dns.a \
  -e dns.resp.ttl -e dns.id \
  -e dns.flags    -e frame.len \
  -E header=y -E separator=, -E quote=d -l \
  | python3 extractor.py | grep entropy

extractor.py — Flow Storage

A global flows dictionary (defaultdict) holds one record per unique src_ip–dst_ip pair. Each record accumulates data across multiple packets before features are computed.

FieldTypeWhat's stored
timestampslist[float]Unix timestamp of each packet in the flow
packet_sizeslist[int]frame.len of each packet
ttlslist[int]DNS response TTL values seen
a_recordsset[str]Unique resolved IP addresses (A records)
domainstrThe queried domain name
src_ip / dst_ipstrFlow endpoints
05

Feature List

build_features() is called only when a flow has ≥ 2 packets. It computes the following features:

duration
max(timestamps) − min(timestamps) in seconds
packets_rate
Number of packets divided by flow duration
mean / std / variance
Packet size statistics across the flow
coefficient_of_variation
std / mean — measures size consistency
character_entropy
Shannon entropy of subdomain characters — high = suspicious
numerical_percentage
Fraction of digit characters in the subdomain
max_continuous_numeric_len
Longest consecutive run of digits in subdomain
max_continuous_alphabet_len
Longest consecutive run of letters in subdomain
vowels_consonant_ratio
Measures linguistic naturalness of the subdomain
distinct_ttl_values
Number of unique TTL values seen in the flow
ttl_values_min/max/mean/median
TTL distribution statistics
distinct_A_records
Number of unique IPs returned — high = fast-flux DNS
06

extractor.py — Full Source

python 
import sys
import csv
import math
import json
import httpx
import io
from collections import defaultdict, Counter
from datetime import datetime
from statistics import mean, median

BACKEND_URL = "http://127.0.0.1:8000/analyze"

# =========================
# FLOW STORAGE
# =========================
flows = defaultdict(lambda: {
    "timestamps": [],
    "packet_sizes": [],
    "ttls": [],
    "a_records": set(),
    "src_ip": "",
    "dst_ip": "",
    "src_port": "",
    "dst_port": "",
    "domain": ""
})

FIELDNAMES = [
    "frame.time", "ip.src", "ip.dst",
    "dns.qry.name", "dns.qry.type", "dns.resp.type",
    "dns.a", "dns.resp.ttl", "dns.id",
    "dns.flags", "frame.len"
]

# =========================
# HELPERS
# =========================

def safe_int(x):
    try: return int(x)
    except: return 0

def entropy(s):
    if not s: return 0.0
    freq = Counter(s)
    l = len(s)
    return -sum((c / l) * math.log2(c / l) for c in freq.values())

def max_consecutive(s, condition):
    best = cur = 0
    for ch in s:
        if condition(ch):
            cur += 1
            best = max(best, cur)
        else:
            cur = 0
    return best

def max_same_char(s):
    best = cur = 1
    for i in range(1, len(s)):
        if s[i] == s[i - 1]:
            cur += 1
            best = max(best, cur)
        else:
            cur = 1
    return best if s else 0

def vowel_consonant_ratio(s):
    vowels = "aeiou"
    v = sum(1 for c in s if c in vowels)
    c = sum(1 for c in s if c.isalpha() and c not in vowels)
    return v / max(c, 1)

# =========================
# FLOW UPDATE
# =========================

def update_flow(row):
    src_ip = row.get("ip.src", "")
    dst_ip = row.get("ip.dst", "")
    domain = row.get("dns.qry.name", "")
    ttl    = row.get("dns.resp.ttl", "")
    a_rec  = row.get("dns.a", "")
    pkt    = safe_int(row.get("frame.len", "0"))

    fid = f"{src_ip}-{dst_ip}"
    f   = flows[fid]

    f["timestamps"].append(datetime.now().timestamp())
    f["packet_sizes"].append(pkt)
    f["src_ip"]  = src_ip
    f["dst_ip"]  = dst_ip
    f["domain"]  = domain

    if ttl.isdigit(): f["ttls"].append(int(ttl))
    if a_rec:         f["a_records"].add(a_rec)

    return fid

# =========================
# FEATURE BUILDER
# =========================

def build_features(flow_id):
    f = flows[flow_id]
    if len(f["timestamps"]) < 2:
        return None

    t     = f["timestamps"]
    sizes = f["packet_sizes"]
    ttls  = f["ttls"]
    domain = f["domain"] or ""

    duration    = max(t) - min(t)
    total_bytes = sum(sizes)
    mean_size   = mean(sizes)
    var         = mean([(x - mean_size) ** 2 for x in sizes])
    std         = math.sqrt(var)

    labels = domain.split('.') if domain else []
    tld    = labels[-1]  if len(labels) >= 1 else ""
    sld    = labels[-2]  if len(labels) >= 2 else ""
    sub    = '.'.join(labels[:-2]) if len(labels) > 2 else ""

    ent     = entropy(sub)
    num_pct = sum(c.isdigit() for c in sub) / max(len(sub), 1)

    return {
        "flow_id":                        flow_id,
        "timestamp":                      min(t),
        "src_ip":                         f["src_ip"],
        "dst_ip":                         f["dst_ip"],
        "duration":                       duration,
        "total_bytes":                    total_bytes,
        "packets_rate":                   len(sizes) / max(duration, 1e-6),
        "packets_len_rate":               total_bytes / max(duration, 1e-6),
        "min_packets_len":                min(sizes),
        "max_packets_len":                max(sizes),
        "mean_packets_len":               mean_size,
        "standard_deviation_packets_len": std,
        "variance_packets_len":           var,
        "coefficient_of_variation_packets_len": std / max(mean_size, 1e-6),
        "dns_domain_name":                domain,
        "dns_domain_name_length":         len(domain),
        "dns_subdomain_name_length":      len(sub),
        "dns_top_level_domain":           tld,
        "dns_second_level_domain":        sld,
        "character_entropy":              ent,
        "numerical_percentage":           num_pct,
        "character_distribution":         dict(Counter(sub)),
        "max_continuous_numeric_len":     max_consecutive(sub, str.isdigit),
        "max_continuous_alphabet_len":    max_consecutive(sub, str.isalpha),
        "max_continuous_same_alphabet_len": max_same_char(sub),
        "vowels_consonant_ratio":         vowel_consonant_ratio(sub),
        "distinct_ttl_values":            len(set(ttls)) if ttls else 0,
        "ttl_values_min":                 min(ttls)    if ttls else -1,
        "ttl_values_max":                 max(ttls)    if ttls else -1,
        "ttl_values_mean":                mean(ttls)   if ttls else -1,
        "ttl_values_median":              median(ttls) if ttls else -1,
        "distinct_A_records":             len(f["a_records"])
    }

# =========================
# SEND
# =========================

def send(features):
    try:
        httpx.post(BACKEND_URL, json=features, timeout=5.0)
    except:
        print(json.dumps(features))

# =========================
# MAIN LOOP
# =========================

def main():
    for line in sys.stdin:
        line = line.strip()
        if not line or line.startswith("frame.time"):
            continue
        reader = csv.DictReader(io.StringIO(line), fieldnames=FIELDNAMES)
        row    = next(reader)
        fid    = update_flow(row)
        feat   = build_features(fid)
        if feat:
            send(feat)

if __name__ == "__main__":
    main()

dns_sim.py — Traffic Simulator

Before you have real attack traffic, use this script to test the pipeline end-to-end. It fires 50 DNS queries — roughly half to legitimate domains and half to randomly-generated subdomains that mimic DNS tunneling.

python 
import os
import random
import string

def normal():
    domains = ["google.com", "ensia.edu.dz", "facebook.com", "wikipedia.org"]
    return random.choice(domains)

def malicious():
    sub = ''.join(random.choices(string.ascii_lowercase + string.digits, k=25))
    return f"{sub}.evil.com"

for _ in range(50):
    domain = normal() if random.random() < 0.5 else malicious()
    os.system(f"dig {domain} > /dev/null")
08

Detection Logic — Normal vs Malicious

The features are designed to expose the statistical difference between human-readable domain names and randomly-generated DGA/tunnel subdomains.

PropertyNormal domainDGA / Tunnel domain
Subdomain length Short 0–10 chars Long 20–40+ chars
Character entropy Low 2.0–2.8 bits High 3.5–4.5 bits
Digit percentage Near 0% ~20–40%
Vowel/consonant ratio Natural ~0.4 Random ~0.2–0.6
Distinct A records 1–2 IPs Many (fast-flux)
Thresholds are starting points. Use character_entropy > 3.5, numerical_percentage > 0.2, or subdomain_length > 20 for simple rules. Your ML model will learn better boundaries from labeled data.
